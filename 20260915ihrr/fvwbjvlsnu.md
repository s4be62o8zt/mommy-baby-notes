# 取卵是个怎样的过程？会痛么？

> 更新时间：2026-09-15 (UTC+8)

取卵是个怎样的过程？会痛么？更新时间:2022-09-19

目前，已被越来越多的人所了解和熟悉，但并不是所有人都清楚地知道手术前的取卵过程。

常见取卵方法

1.腹腔镜取卵：

通常在全麻下在手术室进行，在患者肚脐或脐下置入一根长管状像望远镜一样的镜子。在腹腔镜观察下，医生用针通过腹壁进入卵泡，将卵子和卵泡液吸出。目前辅助生殖一般不用此方法取卵。

2.经阴道取卵：

这种相对简便和安全的方法加快了取卵的效率，能在局麻下进行，并且可以和各种不同的辅助生殖技术(ART)相结合。在阴道B超引导下穿刺采卵，术前肌肉注射度冷丁镇痛。手术过程5-10分钟，手术快，小不需住院。

取卵过程

1. 消毒和冲洗阴道;

2. 取卵时，医生要先进行探针穿刺，将B超探头套上一个胶皮套，在探头固定一根长长的穿刺针，其尾部连接着负压吸引胶管;

3. 探头进入女性阴道，B超显示屏马上可以看到蜂窝状的卵巢，医生根据显示屏所显示操纵探头上的针管，依次抽吸每一个玄色的蜂窝，吸出卵泡里所有的液体。液体顺着穿刺针进入一个个试管;

4. 装满液体的试管，通过传递窗，由助手放入胚胎培养室工作台上的试管架里;

5. 培养室的操纵员做接应，一个接一个地把试管里的液体倒入小圆玻璃皿内，并在显微镜下拣吸出卵子，注入另一个培养皿里，等待催熟。

取卵手术痛不痛？

绝大多数患者反映取卵时的程度是可以忍受的，主要感觉是下腹部酸胀及轻微的刺痛、。但由于每个人对疼痛的阈值不一样，或由于体质关系对疼痛比较敏感，反之，许多人觉着并不很痛。有部分患者甚至觉得取卵手术本身并没有什么感觉，但利用扩阴器撑开阴道并左右转动进行阴道擦洗消毒的过程比取卵时痛。

整个取卵手术过程，正常情况下，需10 ~20分钟左右，但有些女性的卵巢位置异常，医生需要按压患者的腹部，可能使得患者不适感增加。

无痛取卵

杜冷丁镇痛

一般在取卵前5-10分钟采用臀部肌肉注射的方法给予杜冷丁50mg，因为药物起效时间不定，所以止疼效果不确定，存在一定的个体差异性。不良反应有、头痛、出汗、、等。

但是由于个体差异和盆腔解剖位置的不同，镇痛效果往往不是非常理想，导致病人过度、惧怕疼痛以及取卵时无法充分配合术者，对取卵手术的安全和获卵数目产生不利的影响；同时，还会出现头晕、出汗、恶心及呕吐等不良反应。因此无痛取卵成为众多患者的迫切需求。

静脉

在手术前1-2分钟静脉使用镇静类药物，药物起效快、效能强；患者舒适，镇痛效果确切。适用于①惧怕疼痛，无法忍受取卵操作者；②者；③卵泡监测时卵巢位置较高预计穿刺取卵困难者；④卵泡数目较多，估计取卵时间较长者等几种情况。

静脉全身麻醉使取卵者在取卵过程中暂时失去意识和感觉，在无痛苦下完成取卵手术。目的是消除患者对取卵手术的紧张与恐惧。

无痛取卵的优点主要在于安全、舒适、苏醒较快，简单的说，一觉醒来，取卵即结束，没有任何痛苦记忆。

什么时候开始麻醉呢？一般是在患者进入取卵室，取卵工作准备就绪后，在医生实施取卵手术之前使用静脉麻醉药物，待患者进入睡眠状态后，医生才开始取卵。无痛取卵手术结束后醒来是什么感觉呢？多数患者会有头晕、想睡觉等感觉，这些都是正常的麻醉苏醒后表现，10～15分钟后患者基本清醒，休息30分钟，生命体征平稳，能正常沟通交流，无头晕、疼痛等不适感觉，即可离开休息室。

静脉麻醉会影响智力吗？

对于健康成人来讲静脉麻醉对智力是无影响的，麻醉药物在常规临床剂量都不会直接损伤到大脑，等到药物代谢完全后不会有任何影响。手术时麻醉医生一直陪护在患者身边，适时监护、调控使患者的生命体征处于适当水平，而不出现等情况。

静脉麻醉对卵子有影响吗？

在已发表的文章中证实静脉麻醉药物对卵子的质量、受精率及妊娠率等与未行麻醉者相比并无明显差异。

尽管静脉麻醉下取卵在我国尚未普遍应用，但随着人们生活质量、医疗水平的提高和医疗条件的改善，患者对麻醉下取卵的需求将越来越多。目前国外多数国家的IVF-ET中心将静脉麻醉下取卵作为常规治疗。麻醉下取卵可以将手术的疼痛或不适降到最低点，这样既能够保证手术的顺利进行，又能满足患者生理、心理的需求。
