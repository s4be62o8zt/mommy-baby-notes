# 诺贝尔奖获得者来了！国际神经科学领域高水平对话交流

> 更新时间：2026-09-16 (UTC+8)

省医关注

9月7日上午，诺贝尔生理学或医学奖获得者、挪威科技大学卡夫利科系统神经科学研究所和记忆生物学中心创始主任爱德华・莫索尔教授一行莅临我院进行学术交流。访问期间，莫索尔与我院专家学者座谈，为医院与国际神经科学领域权威专家开展高水平对话与务实合作提供了契机。

北京世诺医学交流中心执行秘书长苏燕、海外事务负责人陈林楚、河南中心负责人孙涛陪同访问。我院党委书记、院长郝义彬，在郑院领导班子成员及相关职能部门与临床科室负责人参加交流座谈。副院长王梅云主持座谈会，并就医院整体发展、临床医学研究投入与成果，以及在神经科学领域的最新探索作了系统介绍。

爱德华・莫索尔一行先后参观了我院院史馆和脑科学与脑机接口创新转化中心，详细了解了河南省脑健康及碳硅融合创新转化研究重点实验室在脑机接口（脑机智能）创新转化研究平台、分子机制评估与验证平台及公共服务平台等方面取得的科研进展，并对我院在脑机接口领域的前沿成果给予高度评价。

近日，我院成功实施了河南首例无线微创植入式脑机接口手术，标志着河南脑机接口技术在临床转化取得关键性进展。

神奇一幕！河南首例脑机接口植入者成功开机！

此次手术植入的无线微创脑机接口（NEO）是我国完全自主研发的脑机接口技术。国内仅有十余家医院通过筛选成为临床研究分中心，河南省人民医院是其中之一，也是河南唯一一家。

未来，我院还将依托近日成立的“脑机接口临床研究中心”，陆续开展脑机接口相关临床实验，在脑重大疾病等关键领域更好地应用落地，为健康中国战略提供科技支撑，让科技之光惠及更多中原百姓。

座谈会上，郝义彬在欢迎致辞中表示，莫索尔教授作为神经科学领域国际公认的权威专家，关于海马—内嗅皮层“网格细胞”与“位置细胞”的开创性发现，不仅奠定了空间认知与记忆机制的理论基石，更为阿尔茨海默病、帕金森病等重大神经退行性疾病的早期诊断、干预策略及人工智能神经网络模型的构建提供了划时代的研究范式。跨越学科边界的科学贡献，既彰显了“敢闯无人区”的科学家精神，更践行了“医学济苍生”的崇高追求，这与我院在神经疾病诊疗领域的探索方向高度契合。期待以此次座谈为起点，与莫索尔教授团队在神经疾病精准诊疗技术研发、科研平台共建、人才联合培养等方面建立长期合作，让国际先进经验与中原医疗实践深度融合，共同为破解神经疾病难题、构建人类卫生健康共同体贡献力量。

爱德华・莫索尔围绕大脑的时间与空间机制进行了主题报告。他围绕人类大脑的结构与功能，以深入浅出的讲解，阐述了这一复杂器官的基本机制与重要意义，通过视频演示生动展示了神经元内部的电信号传播以及神经网络协同工作的过程，重点探索了海马体和内嗅皮层在空间导航中的作用，强调了时空认知机制的重要性，并介绍了其团队在大脑地图构建与时间感知方面的最新进展，及其在神经退行性疾病早期诊断、干预策略和人工智能模型构建中的应用价值。

在随后的交流环节中，我院专家学者围绕神经科学、认知障碍早期干预、脑机接口技术开发等领域，与莫索尔进行了深入探讨。

王梅云在主持会议时表示，莫索尔的报告既有对基础科研的严谨剖析，又有对医学转化的前瞻思考，使与会者深刻感受到了国际顶尖科学家“从 0 到 1”的创新魄力，拓宽了我院在神经疾病诊疗领域的视野边界。此次交流不仅是一次“知识充电”，更为双方今后的长期合作奠定了坚实基础。
